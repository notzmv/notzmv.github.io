Introduction & Overview

Bismillah al-Rahman al-Rahim (In the name of God, the Most Gracious, the Most Merciful).

Aljamiado English (English Aljamiado / Inglês Aljamiado) is a systematic, morphophonemic adaptation of the Perso-Arabic script designed to write the English language. Modeled directly after the architectural framework of Aljamiado Português, this system adapts historic Perso-Arabic letterforms, orthographic logic, and specialized extensions (such as Ottoman Sağır Kāf ڭ) to transcribe English text cleanly.

This specification formalizes the orthographic engine for English. The system prioritizes:

  1. Morphophonemic Clarity: Distinguishing nominal plural inflection (-hā / ـها) from verbal agreement sibilants (س / ز), preventing cluttered horizontal text flow.
  2. Graphic & Historical Precision: Leveraging Sā (ث) for voiceless th [θ], Zāl (ذ) for voiced th [ð], Sağır Kāf (ڭ) for velar nasal [ŋ], and Vā (ڤ) for [v].
  3. Dual-Track Vowel Flexibility: Providing both direct Matres Lectionis (dropping unpronounced final silent e) and explicit Silent-e Retention (ه / ـہ) to evaluate reading/writing ergonomics.
  4. Keyboard Recommendation (Urdu GBoard): The best mobile keyboard to use is GBoard set to Urdu language, which exhibits the desired orthographic behavior (except for a final he followed by -hā, where you can long-press the key to select the correct second he form).

Dental Fricatives (th: Sā ث vs. Zāl ذ)

  • Voiceless th [θ] maps to Sā (ث): thin → ثن, think → ثنڭ, three → ثرى.
  • Voiced th [ð] maps to Zāl (ذ): this → ذس, the → ذ / ذا, they → ذى.

Velar Nasal (ng: Sağır Kāf ڭ vs. Nūn-Gāf نگ)

  • Option A (Primary - Sağır Kāf ڭ): Uses Ottoman three-dotted Kāf for compact [ŋ]: sing → سڭ, writing → رایتڭ.
  • Option B (Variant - Nūn-Gāf نگ): Uses Nūn-Gāf digraph: sing → سنگ, writing → رایتنگ.

Labial Fricatives & Semivowels (v ڤ vs. w و)

  • v [v] maps to Vā (ڤ): very → ڤرى, voice → ڤویس.
  • w [w] maps to Waw (و): water → واتر, win → ون.

Palatals & Affricates (ch چ, sh ش, j ج, zh ژ)

  • ch [tʃ] → Chā (چ): chair → چیر.
  • sh [ʃ] → Shīn (ش): ship → شپ.
  • j / soft g [dʒ] → Jīm (ج): job → جاب, page → پیج.
  • zh [ʒ] → Žā (ژ): vision → ڤژین.

Initial Vowel Carriers & Alif Madd Rules

Initial vowels require Alif (ا) as graphic carrier: apple → اپل / آپل, in → إن, open → اوپن, art → آرت.

Dual-Track Evaluation: Matres Lectionis vs. Silent 'e' Retention

  • Track A (Direct Matres Lectionis - Default): Silent final e is dropped: make → میك, bite → بایت, note → نوت.
  • Track B (Silent 'e' Retention - Variant): Preserves silent final e with He (ه / ـہ): make → میكہ, bite → بایتہ.

3. Morphophonemic Rules & Domain Mapping

Rule I: Nominal Plural Domain (-hā / ـها)

Plural nouns (-s / -es) attach the graphic logogram -hā (ـها) to eliminate long Sīn tails and distinguish nominal plurals from verbal agreement: books → بوكها, cats → كتها, dogs → داگها.

Rule II: Verbal Agreement & Lexical Sibilants (س / ز)

3rd-person singular present verbs retain explicit phonetic س / ز so they are never confused with plural nouns: he speaks → هى اسپیكس, she runs → شہ رنز. Lexical sibilants retain Sīn/Zāy: this → ذس, was → واز.

Rule III: Verbal Past Tense (-d / -t: ـد / ـت)

Past tense -ed uses surface morphophonemic -d (ـد) or -t (ـت): walked [t] → واكت, played [d] → پلاید, wanted [ɪd] → وانتد.

Rule IV: Selective Silent He (ه / ـہ)

Long vowels drop silent final e by default. Silent He (ه / ـہ) is reserved for short monosyllabic words (be → بہ, me → مہ, she → شہ) or explicit final -es / -as markers.
